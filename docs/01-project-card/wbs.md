## Level 2 breakdown

### 1. Project management
- 1.1 Project card (purpose, scope, technologies, schedule)
- 1.2 WBS and Gantt chart
- 1.3 Responsibility matrix
- 1.4 Risk register (maintained weekly)
- 1.5 Decision log and tool/AI usage log (maintained continuously)
- 1.6 Communication rules and working-time log
- 1.7 Weekly check-ins and meeting notes
- 1.8 Midpoint retrospective (planned 27 Nov)

### 2. Research and requirements
- 2.1 Survey of existing calculators (analysis of existing solutions)
- 2.2 Research on number representation and display behaviour
- 2.3 Requirement gathering (short user questions or observation)
- 2.4 Requirements specification, edge-case catalogue
- 2.5 Traceability matrix maintenance
- 2.6 Requirements baseline review

### 3. Design and prototype
- 3.1 Wireframes and visual design
- 3.2 Architecture (engine, interface, file layout)
- 3.3 Data-flow diagram
- 3.4 State diagram of calculator behaviour
- 3.5 Display formatting and overflow rules (D3)
- 3.6 Interactive prototype
- 3.7 Design review

### 4. Implementation
- 4.1 Repository and test-runner set-up
- 4.2 Calculation engine (test-first)
- 4.3 Display formatting
- 4.4 User interface (HTML, CSS)
- 4.5 Wiring interface to engine
- 4.6 Keyboard support and accessibility
- 4.7 Error handling and edge cases
- 4.8 Code reviews

### 5. Testing and quality assurance
- 5.1 Test plan
- 5.2 Unit tests, including floating-point, large, small and overflow cases
- 5.3 Randomised key-sequence test
- 5.4 Playwright browser tests (later phase, needs approval to install)
- 5.5 Manual test execution and cross-browser checks
- 5.6 Accessibility checks
- 5.7 Security note
- 5.8 Bug log and test report

### 6. Documentation
- 6.1 Report outline and chapter drafts
- 6.2 Diagram and screenshot collection (real screenshots only)
- 6.3 User guide (one page)
- 6.4 README and delivery instructions
- 6.5 Integration, consistency review and final report

### 7. Presentation and defence
- 7.1 Presentation outline (about 10 minutes, to confirm)
- 7.2 Final presentation slides
- 7.3 Demo script and backup plan
- 7.4 Rehearsals
- 7.5 Defence on 18 December 2026
