# Working-Time Log (template)

**Status:** Empty template. **No hours have been recorded.** Every cell for hours is blank on purpose.
**Last updated:** 2026-10-31
**Why this exists:** The professor's draft-contents list asks for "records of working time of members, kept by the project manager" (slide 32, item 5, guidance). See traceability item P-16.

## Rules

1. Each student records only their own real working time, on the day it happens or soon after.
2. Round to the nearest 15 minutes. Use decimal hours (1.25 = 1 h 15 min).
3. Link each entry to a work package from the [WBS](../01-project-card/wbs.md) (WP1 to WP7).
4. Count: research, design, coding, testing, writing, reviewing, meetings. Do not count time when you were not working on the project.
5. Do not edit another student's entries. If a mistake is found, the owner corrects it and adds a note.
6. Time spent *supervising or correcting AI-generated output* is working time and is recorded normally. AI use itself is recorded in the [tool and AI usage log](tool-ai-usage-log.md).
7. The project manager (provisionally Student 1) checks the log weekly and copies the totals into section 3. The check is recorded only when it actually happens.

Do not fill in estimates or "expected" hours. Planned effort lives in the WBS, not here.
